# LLM Dojo

Materials from [LLM Dojo](https://rupnikj.github.io/LLM-Dojo/), an open biweekly meetup at the Jožef Stefan Institute in Ljubljana. We meet to follow what is happening in large language models — news, hands-on sessions, and member presentations — with a focus on building and daily use.

Everything here is served directly via GitHub Pages: each subfolder is a self-contained project (usually a single `index.html` with no build step), and `notebooks/` holds hands-on Colab notebooks from sessions.
