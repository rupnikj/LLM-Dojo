# LLM events, 17 September – 1 October 2026

A single self-contained page: seven threads, an interactive timeline of 30 dated events, an interactive capability-cost chart, a tier table, and a chronology. No build step; edit `index.html` directly.

## Sources and method

- The eight AINews daily issues covering 17–30 September, read in full. Every event links to its dated issue on latent.space, where AINews now publishes; 17 events also link a primary source (the announcing account on X, a vendor page, or an independent evaluator).
- The capability-cost chart and tier table use the dataset behind CatalystNeuro's LLM Cost Frontier dashboard (Artificial Analysis data), as of 1 October 2026. Scores use Intelligence Index v4.2 and are not comparable with the figures on the summer page, which predate the index rebuild.
- Assembled with Claude; the grouping and emphasis are the dojo's.

## Updating

Event data lives in one `EVENTS` array inside `index.html`; the timeline, per-thread lists and chronology all render from it. The frontier widget's data is a second inline array in the same file.

## Note on sources

AINews moved from news.smol.ai to latent.space during this period; the old archive lags by about a week. `https://www.latent.space/feed` carries recent issues in full, with links intact.
